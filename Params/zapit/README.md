# Zapit configurations

The known-good Zapit configuration files (`.yml`), loaded in Zapit on the rig. Which preset uses which file, and how to add or change one: [ZAPIT.md](../../ZAPIT.md#configurations).

**To recover:** copy them here from `Desktop\zapit_protocols` on rig 31108.

Change a configuration only by committing a new version here; the commit is its version, and it is what each opto or masking session records ([ZAPIT.md](../../ZAPIT.md#what-to-record-with-each-session)).
